Amazon Clone

A modern and responsive Amazon-inspired e-commerce web application built using React.js and JavaScript. This project replicates the core shopping experience of Amazon,cart management, and responsive design.

📌 Features

- Product Listing Page
- Product Search Functionality
- Shopping Cart Management
- Responsive User Interface
- Reusable React Components
- Modern React Hooks
- Dynamic Rendering of Products
- Mobile-Friendly Design

🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- React Hooks
- Git & GitHub
- GitHub Pages

⚡ Installation & Setup

1. Clone the repository

git clone https://github.com/divya-pasupulet05/Amazon-Clone.git

2. Navigate to project folder

cd Amazon-Clone

3. Install dependencies

npm install

4. Start the development server

npm start
